APPLICATION PLUGINS

Your tabs, connected.

Install BeaconHop first, then connect a plugin from BeaconHop → Application plugins. Plugins need the desktop app running.

VS Code

Switch text, diff and notebook editor tabs across groups. The extension runs in VS Code's local UI host.
