# BeaconHop

Confirmed by the user on 2026-10-28.

Beacon is a signal that identifies a destination. Hop is the short action that takes you there. The name supports the current letter-hint interaction and future forms of guidance without restricting the product to windows, screens, keyboard letters or eye tracking.

Product category: work navigation. First release: a window navigator with visual hints, previews and search.

Tagline: **Follow the hint. Hop to your work.**

The vector logo combines a B, a warm beacon and a short approach trail. Its source is `public/beaconhop.svg`; `npm run icons` produces the application icon families. The palette pairs violet navigation cues with an amber signal. Brand/domain/trademark registration is not represented as completed by this implementation.
