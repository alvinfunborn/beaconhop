BROWSER SETUP

Connect your tabs.

Install and run the BeaconHop desktop application first. The browser extension alone cannot switch tabs through BeaconHop. No BeaconHop account is required.

Chrome

The Chrome extension's assigned ID is ibfbnolmkggfokdaohfdobfjklcccjma. It has been submitted to the Chrome Web Store and is awaiting review. Once available, install BeaconHop Tabs from the Chrome Web Store, then register its local Native Messaging host using the command for your system.

macOS

With BeaconHop installed in Applications, run this in Terminal:

/Applications/BeaconHop.app/Contents/MacOS/beaconhop --register-browser-host chrome ibfbnolmkggfokdaohfdobfjklcccjma

Windows

Start BeaconHop, then run this in PowerShell. It finds the executable of your running BeaconHop application:

& (Get-Process beaconhop | Select-Object -First 1 -ExpandProperty Path) --register-browser-host chrome ibfbnolmkggfokdaohfdobfjklcccjma

Verify the connection

  1. Keep BeaconHop running. Enable the browser plugin in BeaconHop → Application plugins.
  2. Open the extension popup and click Reconnect. It should show Connected.
  3. Open two ordinary web tabs in the same browser window. Focus that window, invoke the tab shortcut configured in BeaconHop, and select the other tab. It should become active.
  4. Page previews are optional. Enable them in the popup, grant the requested website permission, and visit an ordinary web page. Private browsing tabs are excluded. Disable previews to clear the extension cache and revoke its optional permission.

Edge

Edge 1.0.0 has been submitted to Microsoft Edge Add-ons and is awaiting review. Its assigned extension ID is acidkhplkenimagnendhehianijedgdf. Existing developer-mode setup remains available from the plugin installation guide. Edge and Chrome have different extension IDs; register each browser with its own ID.

macOS

/Applications/BeaconHop.app/Contents/MacOS/beaconhop --register-browser-host edge acidkhplkenimagnendhehianijedgdf

Windows

& (Get-Process beaconhop | Select-Object -First 1 -ExpandProperty Path) --register-browser-host edge acidkhplkenimagnendhehianijedgdf
